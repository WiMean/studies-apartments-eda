# Исследование объявлений о продаже квартир

**Задача.** Данные сервиса Яндекс.Недвижимость по Санкт-Петербургу и соседним населённым пунктам. Научиться определять рыночную стоимость объектов и установить параметры для автоматического отслеживания аномалий и мошеннической деятельности.

**Что сделано.** Обработка пропусков и аномалий, добавление признаков (цена за м², этаж, удалённость от центра), анализ влияния факторов на стоимость, определение границ аномальных значений.

**Стек.** Python, pandas, NumPy, Matplotlib, Seaborn, SHAP
